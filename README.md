# Tiny-AI-Powered-App

## How to stup the API
    USE <pip install -r reqirements.txt > to install the required file to run this project 
    1 Use the groq website there you can find the api section after login or Signup
    2 create a new API for the AI QNA bot
    3 create a .env folder 
    4 paste the api like GROQ_API_KEY = <your api key > and save it 
    5 you need to type the code to run streamlit app  <streamlit run <location of path>\Tiny-AI-Powered-App\streamlit_app.py>
